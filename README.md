# Demon Slayer: Kimetsu no Yaiba

A cinematic, anime-inspired fan website featuring character showcases, visual effects, and scroll-based animations.

## Project structure

```text
demon-slayer-site/
├── README.md
├── index.html
└── assets/
    ├── backgrounds/
    ├── chars/
    ├── effects/
    ├── ui/
    └── showcase.mp4
```

## Run locally

Open `index.html` in a browser, or use the Live Server extension in Visual Studio Code.

## Publish with GitHub Pages

1. Upload the contents of this folder to the root of your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/ (root)`, then save.

The website entry point must remain `index.html` in the repository root. Keep the `assets` folder beside it so image, effect, and video paths continue to work.

## Technologies

- HTML5
- CSS3
- JavaScript
- GSAP and ScrollTrigger (loaded externally)

An internet connection is required for externally hosted libraries and fonts.
